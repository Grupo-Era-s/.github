# Configuração da organização — Grupo ERA&S

Este repositório centraliza o **perfil público** e os **padrões de documentação** usados pela organização Grupo ERA&S no GitHub.

## Estrutura

- `profile/README.md` — apresentação pública da organização.
- `CONTRIBUTING.md` — regras básicas para colaborar nos projetos.
- `README_TEMPLATE.md` — modelo de README para novos repositórios.
- `PULL_REQUEST_TEMPLATE.md` — modelo simples para futuras Pull Requests.

## Objetivo

Manter os repositórios da ERA&S fáceis de entender, manter e evoluir, sem adicionar processos desnecessários para uma equipe pequena.

> Nunca armazene senhas, tokens, chaves de API ou arquivos `.env` neste repositório.
